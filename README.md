# Observatorio de viajes presidenciales

Registro público de los viajes al exterior del presidente de Panamá, con cada viaje contado por país visitado.

- **index.html**: la página completa (datos, estilos y código en un solo archivo). No requiere instalación.
- Para actualizarla, edita la lista `D` dentro de `index.html` (una fila por viaje: número, gira, fecha, país, ciudad, motivo, estatus, tipo de fuente) y la fecha de actualización del pie.
